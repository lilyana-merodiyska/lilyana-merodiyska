# Hi, I'm Lilyana 👋

I'm an aspiring **Manual QA Engineer** from Ruse, Bulgaria, looking for my first role in software testing.

## My background
I currently work as a **behaviour therapist**. My daily work is built on skills that carry over directly to QA:

- **Careful observation** - noticing small details and changes in behaviour, the same way I look for unexpected behaviour in software
- **Accurate documentation** - recording what happened, in which situation and with what result, clearly enough for someone else to follow
- **Structured, step-by-step work** - following a plan, checking the result of each step and adjusting
- **Clear communication** - explaining problems and results in simple words to people with different backgrounds
- **Patience and attention to detail** - repeating checks until the picture is complete

## What I do in QA
- Analyse and write requirements, and turn them into test scenarios and test cases
- Plan testing: scope, strategy, risks, entry and exit criteria
- Design tests with techniques such as Equivalence Partitioning, Boundary Value Analysis, Decision Tables and State Transition
- Execute functional, non-functional, exploratory, smoke, regression and cross-browser testing
- Report defects with clear steps, severity and priority, and retest them
- Test web applications, REST APIs and databases (SQL)
- Write test summary reports and keep everything traceable: requirement → scenario → test case → defect → retest
